# V0.3 — fonctions sociales
Intégrations : inscription et sessions, profils modifiables, approbation des partenaires par administrateur, suivis, conversations privées, demandes de rendez-vous avec acceptation/refus/annulation, avis liés à une interaction vérifiée et modération.

## Vérification locale
1. `bash scripts/setup-local.sh`
2. `npm install && npm run check`
3. `npm run dev -- --hostname 127.0.0.1`
4. Vérifier /compte/, /mon-espace/, /admin/communaute/.
5. Créer deux comptes de test; approuver un profil depuis le compte admin; vérifier abonnements, création de conversation, accès refusé aux tiers.
6. Vérifier qu'un avis sans interaction réelle est refusé.

## Non prêt pour production
Vérification email et récupération de mot de passe, limitation de débit distribuée, protection anti-spam, politique de conservation et RGPD, signalement et blocage des utilisateurs, tests E2E et tests de sécurité. Ne pas déclarer la V0.3 commercialement prête avant ces vérifications.
