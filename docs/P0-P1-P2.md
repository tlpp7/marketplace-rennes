# Plan de correction P0/P1/P2

P0 : jetons SMTP, vérification transactionnelle, origine fixe des liens email, CI en jobs indépendants.
P1 : tests unitaires, tests authentification, isolation et état métier ; compléter anti-abus et sécurisation avant lancement.
P2 : parcours navigateur Playwright, navigation mobile et critères d'accessibilité.

## Exécution
```bash
npm install
npm run test:unit
npm run check
npx playwright install --with-deps chromium
npm run test:e2e
```
Les tests CI utilisent une base PostgreSQL et un serveur SMTP fictif. Ce ne sont pas des tests de paiement réel, ni un audit d'intrusion. Ne pas publier le site commercialement sans les contrôles manquants.
