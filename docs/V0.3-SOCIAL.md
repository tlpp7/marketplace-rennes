# V0.3 : comptes, suivis, avis, messagerie, rendez-vous — fondation serveur

## Nouveau prérequis majeur
Cette étape supprime l'export statique : Next.js doit être exécuté sur un serveur Node.js persistant. Cloudflare Pages en mode hébergement statique ne peut plus exécuter ces API. Utiliser une machine Linux (PC gamer / VM de production) avec PostgreSQL. Jamais exposer la base sur Internet.

## Mise en place en environnement isolé
1. Installer PostgreSQL 15+ et créer une base et un compte aux privilèges limités.
2. Exécuter `psql "$DATABASE_URL" -f infra/sql/001_social.sql`.
3. Définir dans `.env.local` : `DATABASE_URL=postgresql://...`, `SESSION_SECRET=<clé aléatoire de 32 octets minimum>`, `SEO_PUBLIC=false`.
4. Installer les dépendances puis `npm run build && npm run dev`.
5. Consulter `/compte/` puis `/mon-espace/`.
6. Ne jamais committer `.env.local`.

## Portée réelle
- Inscription/connexion : scrypt + session HTTP-only, table sessions.
- Suivi : possible uniquement vers les comptes de revendeurs approuvés.
- Avis : uniquement si une ligne `verified_interactions` atteste une transaction terminée ; restent en attente de modération.
- Messagerie : échanges entre membres autorisés, via une conversation enregistrée en base.
- Rendez-vous : demandes à des profils prestataires approuvés ; pas de calendrier de disponibilités ni confirmation automatique.

**Le catalogue JSON et les quatre profils fictifs ne créent aucun compte approuvé.** Un processus de validation de véritables partenaires et de modération est nécessaire avant l'ouverture. Aucun utilisateur ne peut s'auto-attribuer le statut vérifié.

## Impératifs avant exposition publique
Tests d'intégration et audit sécurité, confirmation email, réinitialisation de mot de passe, anti-spam et limitation de débit, modération/signalement, effacement/export RGPD, sauvegardes, gestion des cookies, contrôle strict des accès, politiques de conservation, validation des créneaux et annulation, antifraude. Les API actuelles constituent une fondation de développement et ne sont pas prêtes à accueillir de vrais clients.
