# V0.2 — Profils de revendeurs et services textiles

## Périmètre implémenté
- Répertoire public des profils (exemples fictifs).
- Fiches détaillées avec activités et spécialités.
- Recherche, filtre revendeur / service.
- Navigation depuis le dépôt-vente.
- Préparation pour une future base relationnelle.

## Non implémenté
- Comptes utilisateurs, authentification, messagerie, abonnements, avis, réservation ou paiement.
- Vérification d'identité, qualifications et modération.
- Prestataires actifs.

## Futur schéma
User -> Profile -> Listing / ServiceOffer
User -> Follow -> Profile
Order or CompletedService -> Review -> Profile
Conversation -> Participants -> Messages

Chaque avis devra être lié à une interaction vérifiée ; les messages et les données personnelles ne seront jamais intégrés à un export statique public.

## Déploiement
npm install
npm run check:profiles
npm run build

Aucune dépendance serveur ou abonnement ajouté. Le répertoire JSON est public et contient seulement des exemples fictifs.
