# Validation V0.2
Couverture ajoutée : structure des quatre profils fictifs, unicité ID/slug, absence de coordonnées externes, annuaire et filtres, recherche vide, pages détails/404, navigation clavier/mobile, et API des partenaires réels approuvés avec PostgreSQL.

Commandes : `npm install`, `node --test scripts/check-profiles-v02.mjs`, `npm run test:e2e -- tests/e2e/profiles-v02.spec.mjs`.

Un test validé ne signifie pas que de vrais partenaires ont été recrutés, ni qu'un produit commercial est prêt. Les données fictives restent des démonstrations.
